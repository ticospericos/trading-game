# Trading Game

## Project Documentation

The Trading Game is an interactive simulation that allows players to engage in trading activities using a variety of strategies. It provides a realistic experience of market fluctuations and decision-making processes.

## Features
- Real-time market data simulation
- Multi-player trading environments
- Various trading strategies to choose from for players
- Detailed analytics and performance tracking

## Setup Instructions

To set up the project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ticospericos/trading-game.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd trading-game
   ```

3. **Install dependencies**:
   Make sure to have [Node.js](https://nodejs.org/) installed. Run:
   ```bash
   npm install
   ```

4. **Run the application**:
   ```bash
   npm start
   ```

5. **Access the game**:
   Open your browser and go to `http://localhost:3000` to start playing!
